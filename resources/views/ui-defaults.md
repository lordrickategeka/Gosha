# Gosha Project UI Design Standards

## Default Form Styles
- Use compact padding: `p-3` for containers, `px-2 py-1` for inputs, `gap-2` for grids.
- Font sizes: `text-xs` for labels, `text-sm` for inputs, `text-base` for section headings, `text-lg` for main headings.
- Rounded corners: `rounded` for inputs and containers.
- Button sizes: `px-4 py-1` for actions, `text-xs` for button text.
- Use `focus:ring-1` for input focus, not `focus:ring-2`.
- Use `max-w-3xl` for main form containers.
- Use `space-y-4` for vertical spacing between form sections.

## Default Table Styles
- Use compact table: `table-compact` or `text-xs` for table text.
- Table container: `rounded`, `shadow-sm`, `p-3`, `bg-white`.
- Table header: `text-xs font-semibold`, `bg-gray-50`.
- Table rows: `hover:bg-gray-50`, `border-b`.
- Action buttons: `px-2 py-1`, `text-xs`, `rounded`.
- Row numbering: always show as first column.
- Use avatars, badges, and icons as previously implemented.

## General
- All new forms and tables must use these compact, modern styles by default.
- When updating or creating new UI, refer to this file for class and layout guidance.
- For consistency, always use the smallest practical spacing and font size for admin UI.
